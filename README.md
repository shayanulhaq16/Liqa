# Liqa 💚
### Simple conversations, closer connections.

Liqa is a clean, WhatsApp-inspired chat UI built with HTML and CSS. It features a welcome page and two separate chat screens with a familiar green-and-cream theme and a responsive layout.

> **Project Status:** Front-end prototype. Real-time messaging and authentication are not implemented yet.

## ✨ Features

- 💬 WhatsApp-inspired chat interface
- 💚 Clean green, white, and cream theme
- 🏠 Welcome page with links to both users
- 👤 Separate chat pages for User 1 and User 2
- 📱 Responsive design for mobile and desktop
- 🎨 Separate CSS files for each chat page
- 🚀 Ready for static deployment on Vercel

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (for future functionality)
- Vercel for deployment

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Select User 1 or User 2 to explore the chat interface.

For a better development experience, use the Live Server extension in VS Code.

## 🌐 Deployment

Liqa can be deployed on [Vercel](https://vercel.com/).

1. Push your project to GitHub.
2. Import the repository into Vercel.
3. Select **Other** as the framework preset if needed.
4. Keep the project root as the root directory.
5. Deploy your website.

Vercel will use `index.html` as the main welcome page.

## ⚠️ Current Limitations

- The chat interface is currently static.
- Messages are not yet sent or saved.
- Supabase is not connected.
- Separate pages alone do not secure access between users.
